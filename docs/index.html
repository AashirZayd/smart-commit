[ SYSTEM FEATURES ]

Engineered for Predictability & Speed

Built for developers who value speed, privacy, and standardized repository history.

◈ 01. STAGED-DIFF ANALYSIS

Unlike simple filename matchers, Smart Commit analyzes the actual content changes in your staged diff. Fixes, features, refactors, docs, and tests are weighted by concrete code modifications.

  • ✔ Error handling changes detected as fix
  • ✔ Balanced rewrites detected as refactor
  • ✔ Pure deletions and renames handled safely
◈ 02. HIERARCHY-AWARE SCOPE

Understands nested folder hierarchies, monorepo architectures (packages/*, apps/*), and normalizes Windows backslashes automatically.

  • ✔ Skips generic folders (src/, lib/, core/)
  • ✔ Derives meaningful package and domain scopes
  • ✔ Refuses to invent certainty when scopes conflict
◈ 03. PRE-FLIGHT GIT INTEGRITY

Validates repository state before executing actions. Protects against accidental commits during rebase conflicts, unresolved cherry-picks, or bare repos.

  • ✔ Non-git directory safe exit (code 1)
  • ✔ Staging empty detection (code 0)
  • ✔ Merge conflict blockers with clear diagnostics
◈ 04. FAST CLI WORKFLOWS

Run interactively to select commit types, customize scopes, and review prompts — or use --quick to commit instantly with auto-inferred metadata.

  • ✔ Full interactive questionnaire with defaults
  • ✔ --quick for single-command instant commits
  • ✔ --no-emoji for strict text-only environments

How To Use Smart Commit

Integrates directly into your existing Git command-line workflow in three steps.

[ 01 ]

Stage Your Changes With Standard Git

Use your standard git add command to stage the files you want to include in your next commit. Smart Commit operates strictly on staged changes, leaving unstaged files untouched.

git add src/checkout/cart.js
[ 02 ]

Launch Smart Commit

Run smart-commit in your terminal. The tool will validate the repository, inspect the staged diff, suggest the inferred type and scope, and prompt you for the message.

smart-commit
[ 03 ]

Or Use Quick Mode For Instant Execution

Skip interactive prompts entirely by passing --quick (or -q). Smart Commit will infer the type and scope, formulate the message, and commit in a single step.

smart-commit --quick

[ SPECIFICATION REFERENCE ]

Conventional Commits Specification (v1.0.0)

Standard commit types supported out-of-the-box by Smart Commit CLI.

feat ✨

A new feature or enhancement for the user or system.

fix 🐛

A bug fix or error resolution in existing functionality.

refactor ♻️

A code change that neither fixes a bug nor adds a feature.

docs 📝

Documentation-only modifications, guides, or README updates.

test 🧪

Adding missing tests or correcting existing test suites.

perf ⚡

A code modification that improves runtime performance.

chore 🔧

Maintenance tasks, tool configs, or auxiliary changes.

build 📦

Changes that affect build systems or external dependencies.

ci 🔄

Continuous integration scripts, GitHub actions, or configs.

Getting Started & Command Reference

Install globally via npm and run anywhere from any terminal.

▼ PACKAGE MANAGER INSTALLATION

Install Smart Commit globally on your system to use the smart-commit command in any repository.

GLOBAL INSTALL (RECOMMENDED)
npm install -g smart-commit-cli
OR RUN DIRECTLY VIA NPX
npx smart-commit-cli
YARN GLOBAL ALTERNATIVE
yarn global add smart-commit-cli
SYSTEM PREREQUISITES:
  • Node.js version 20.12.0 or higher
  • Git version 2.20 or higher installed in system PATH
  • Windows, macOS, or Linux operating system
▼ COMMAND LINE ARGUMENTS & FLAGS

All CLI options are parsed cleanly via standard POSIX flags.

FLAG DESCRIPTION
-q, --quick Commit immediately using inferred type and scope with auto-formulated message.
--no-emoji Disable emoji prefix in the commit message header.
-v, --version Display current version (1.2.0) and exit with code 0.
-h, --help Display command usage, available options, and help reference.
STANDARD EXIT CODE CONTRACT:
0 = Success / Staging Empty / Handled
1 = Git Failure / Invalid State / Error
130 = SIGINT Interruption (Ctrl+C)
