Architecture

Conventional commits,
without the ceremony.

Smart Commit reads the changes you have already staged, infers useful commit metadata using local heuristics, and formats a clean conventional commit directly in your terminal.

📦
Staged Changes
Strictly analyzes files in your Git index (`git add`)
→
🔍
Local Diff Analysis
Inspects patch deltas, line changes, and file statuses
→
🎯
Scope & Type Inference
Determines domain boundaries and semantic change type
→
✨
Conventional Commit
Structured commit ready for history and release notes

Capabilities

Engineered for developer flow.

Deterministic, transparent tools that stay fast and respect your privacy.

🧠

Diff-Aware Type Detection

Analyzes actual additions, deletions, renames, and error-handling modifications in `git diff --staged` instead of relying only on naive filenames.

📂

Hierarchy-Aware Scopes

Extracts meaningful domains (`src/auth/login.js` → `auth`, `packages/payments/...` → `payments`) while gracefully ignoring generic directories.

🛡️

Git Pre-Flight Safety

Protects repository integrity. Verifies Git status, warns on detached `HEAD`, and blocks operations during rebases, cherry-picks, or merge conflicts.

⚡

Quick Mode

Need to commit in one keystroke? Run `smart-commit --quick` to auto-commit using the inferred type and dominant scope instantly.

🛡️

False-Positive Protection

Token-aware matching prevents substring confusion. Files like `address.js`, `debug.js`, or `contest.js` never trigger accidental types.

🔒

100% Local & Private

Your source code never leaves your computer. No telemetry, no background network pings, no cloud models, and no account requirements.

Workflow

How It Works

Seamlessly integrates into your existing Git terminal habits.

01

Stage your changes

Stage specific files or your entire worktree as you normally do.

git add .
02

Run Smart Commit

Launch the CLI to analyze the staged diff and repository topology.

smart-commit
03

Review the suggestion

Confirm or adjust the inferred type, detected scope, and message.

? Commit type: feat (enter)
04

Commit created

A clean Conventional Commit is recorded directly into your Git history.

✨ feat(auth): add login

Inference Examples

Deterministic signals in action.

Here is how Smart Commit classifies real repository changes without guesswork.

Staged Changes Inferred Type Inferred Scope Resulting Commit Header
src/auth/oauth.js added feat auth ✨ feat(auth): ...
src/auth/login.js error handling fix fix auth 🐛 fix(auth): ...
docs/api/endpoints.md docs api 📝 docs(api): ...
tests/auth/login.test.js test auth 🧪 test(auth): ...
src/auth/login.js + README.md feat (code dominates) auth ✨ feat(auth): ...
package.json + package-lock.json chore none 🔧 chore: ...
src/auth/login.js + src/payments/card.js feat none (mixed domain) ✨ feat: ...

Installation

Up and running in seconds.

Requires Node.js ≥ 20.12.0 (native ES Modules). Compatible with macOS, Linux, and Windows.

Global Installation

Install globally via npm to access `smart-commit` anywhere:

$ npm install -g smart-commit-cli

Or Run Instantly via npx

$ npx smart-commit-cli

CLI Commands

smart-commit Interactive guided commit workflow
smart-commit --quick Auto-commit immediately using inferred type and scope
smart-commit --no-emoji Create commits without emoji prefixes
smart-commit --help Display help and command options
smart-commit --version Display current version (1.2.0)

Standardization

Conventional Commits Specification

Smart Commit formats your history in accordance with industry standards:

<type> (<scope>): <description>
feat A new feature or functional addition
fix A bug fix or error correction
docs Documentation updates only
style Formatting changes that do not alter code logic
refactor Code restructuring without new features or fixes
test Adding or modifying automated tests
chore Build tools, dependencies, or configuration
